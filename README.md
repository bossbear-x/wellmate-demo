# WellMate UI Portfolio MVP

既存の WellMate Figma を基準に、UI ポートフォリオで操作デモを見せるために実装した React MVP です。実製品や医療サービスではなく、画面設計・状態設計・AI 活用プロセスを説明するためのプロトタイプです。

## 起動方法

```bash
npm install
npm run dev
```

ターミナルに表示された URL（通常は `http://localhost:5173/`）をブラウザで開きます。

## URL

- 手動操作：`http://localhost:5173/`
- 自動デモ：`http://localhost:5173/?demo=1`
- 自動デモ＋再生ボタン：`http://localhost:5173/?demo=1&controls=1`

自動デモは約 10 秒の一回再生です。ホームから食事記録、選択状態、確認、保存、実データ更新、AI コーチまで進み、AI コーチ画面で停止します。

## 操作フロー

1. ホームの追加ボタン、または下部の「記録」を選択
2. 「食事記録」を選択
3. 食事一覧の「食事を追加」を選択
4. 食事タイプと食品を選択
5. 「次へ」で食事詳細を確認
6. 「この内容で保存」で 420ms の保存状態を表示
7. 更新された摂取カロリーと昼食データを確認
8. 下部の「AI」からプリセット質問を選択

## ビルド

```bash
npm run build
npm run preview
```

## 実装範囲

- React 19 / Vite 8 / 通常の CSS
- 393 × 852 px のモバイル UI（デスクトップ中央表示）
- 固定ステータスバー、固定ヘッダー、独立スクロール領域、固定ボトムナビ
- Figma から書き出したローカル SVG と男性アバター画像
- 食事タイプ・食品の選択状態
- 保存中状態と保存後のデータ更新
- AI Coach のプリセット回答（外部 AI API への接続は行いません）

`dist/` は `npm run build` で生成されます。
